# 開賣提醒

Windows 上的票券開賣提醒小工具。設定開賣時間後，時間快到時會通知你，避免因為忘記或在忙而錯過開賣。

> 這個工具**只負責提醒**，不會自動登入、選位或購票。登入、選位、付款請自己操作。
> 依《文化創意產業發展法》第 10 條之 1，用程式自動購買藝文表演票券屬違法行為。

## 功能

- 可以設定多個場次（名稱、購票網址、開賣時間）
- 開賣前 N 分鐘（預設 10、1 分鐘）跳出 Windows 通知並播放提示音
- 開賣前 30 秒，螢幕右上角出現置頂倒數視窗，精確到 0.1 秒
- 倒數以**購票網站伺服器時間**為準，讀取 `Date` / `Age` 標頭，精確度約 ±0.1 秒；網站連不上時改用國家標準時間（NTP）
- 所有時間固定以台灣標準時間（UTC+8）顯示與輸入
- 可選擇時間到是否自動開啟購票網頁（預設不開）
- 等待期間防止電腦進入睡眠

## 使用方式

**直接執行：** 下載 `開賣提醒.exe` 後雙擊開啟，不需要安裝 Python。

**從原始碼執行（需要 Python 3.10 以上）：**

```powershell
python test\ticket_reminder.py
```

**自己打包 exe：**

```powershell
pip install pyinstaller
python -m PyInstaller --onefile --windowed --name "開賣提醒" test\ticket_reminder.py
```

詳細操作請看 [使用說明.txt](使用說明.txt)。
